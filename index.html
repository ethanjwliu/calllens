Inside the model

The same formula, word by word.

score(class) = Σ log((word count + 1) / total class words)

Each sentence is lowercased and split on whitespace. Punctuation stays attached. Word scores are added, both classes start at zero, and the higher score wins. Exact ties go to Q&A.

An unseen word has count zero and receives log(1 / total class words). A word unseen in both classes can still favor the class with fewer total words. These are classification scores, not probabilities or measured accuracy.

This preserves the instructor’s denominator: total class words. Standard Laplace smoothing would also add vocabulary size to that denominator.

Company speakers are inferred from Prepared speakers and full speaker names mentioned in the same call’s Prepared text. Operator and generic Analyst labels are excluded.

The selected simple filter can miss name variants and retain closing remarks or other company-side Q&A exchanges. All selected text is used for training; no test-set accuracy is claimed.

The Python-trained word counts are bundled with this page. Your input is processed in your browser, with no API call, sign-in, or Colab session.
